LeetCode 1 - Two Sum

Approach:
Brute Force

Idea:
Check every possible pair in the array.
If the sum of two elements equals the target,
return their indices.

Steps:
1. Run outer loop from 0 to n-1.
2. Run inner loop from i+1 to n-1.
3. Check if nums[i] + nums[j] == target.
4. Return indices when found.

Example:

nums = [2,7,11,15]
target = 9

2 + 7 = 9

Answer = [0,1]

Why j starts from i+1?

To avoid:
- Comparing same element with itself.
- Checking duplicate pairs.

Example:
(0,1) is checked
(1,0) is not checked again.

Pattern:
Array
Nested Loop
Brute Force

Time Complexity:
O(n²)

Space Complexity:
O(1)

Learning:
Whenever the problem asks for a pair and no optimization
comes immediately to mind, start with brute force.
Then think about HashMap optimization.
