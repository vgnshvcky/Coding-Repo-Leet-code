LeetCode 2058 - Find the Minimum and Maximum Number of Nodes Between Critical Points

Pattern:
Linked List + Traversal

What is a Critical Point?

A node is a critical point if:

1. Local Maximum
   prev < curr > next

OR

2. Local Minimum
   prev > curr < next

--------------------------------------------------

Approach

Traverse the linked list while maintaining:

prev -> previous node
curr -> current node
next -> next node

Check if current node is a critical point.

--------------------------------------------------

Important Variables

first = position of first critical point
last  = position of latest critical point

Min = minimum distance between consecutive critical points

--------------------------------------------------

Logic

If current node is critical:

First critical point:
    store its position in first

For every next critical point:
    calculate distance from previous critical point
    update minimum distance

Update last with current position

--------------------------------------------------

Example

1 -> 3 -> 2 -> 2 -> 3 -> 2 -> 2 -> 2 -> 7

Critical Points:
3 (index 1)
3 (index 4)

Minimum Distance = 3
Maximum Distance = 3

Answer:
[3,3]

--------------------------------------------------

Why return [-1,-1] ?

If fewer than 2 critical points exist,
distance cannot be calculated.

Example:

1 -> 2 -> 3 -> 4

No critical points

Answer:
[-1,-1]

--------------------------------------------------

Time Complexity

O(n)

Single traversal of linked list.

--------------------------------------------------

Space Complexity

O(1)

Only a few variables used.

--------------------------------------------------

Key Learning

For linked list problems involving local peaks and valleys:

Check:
prev < curr > next

or

prev > curr < next

Store positions instead of nodes when only distances are needed.
