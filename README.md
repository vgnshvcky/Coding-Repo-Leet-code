# Daily-Problem-LeetCode

A repository dedicated to solving LeetCode problems consistently and documenting the learning journey.

## Goals

* Strengthen Data Structures and Algorithms fundamentals.
* Improve problem-solving and analytical thinking skills.
* Prepare for product-based company interviews.
* Build consistency through daily practice.
* Maintain a structured collection of solutions and notes for future revision.

## Repository Structure

Each problem includes:

* Problem name and number
* Java solution
* Approach and intuition
* Time and space complexity analysis
* Important observations and patterns

## Topics Covered

* Arrays
* Strings
* Linked Lists
* Stacks & Queues
* Trees & Binary Trees
* Binary Search
* Recursion & Backtracking
* Dynamic Programming
* Graphs
* Greedy Algorithms
* Sliding Window
* Two Pointers
* Heap / Priority Queue
* Bit Manipulation

## Purpose

This repository serves as a personal DSA journal to track progress, revisit concepts, identify recurring patterns, and stay interview-ready through continuous practice.

**Language:** Java
**Platform:** LeetCode
**Commitment:** Solve and document problems regularly.
